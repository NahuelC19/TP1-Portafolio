# Portfolio Personal - TP1 React

**Descripción breve del proyecto:** 
Aplicación web estática de una sola página construida con React y Vite. Este portfolio personal fue desarrollado para el Trabajo Práctico Nº 1, demostrando la aplicación práctica de componentes, JSX, props, eventos, renderizado dinámico y estado.

## Tecnologías utilizadas
* **React (JSX):** Librería principal para la construcción de la interfaz.
* **Vite:** Entorno de desarrollo y construcción.
* **HTML5 & CSS3:** Maquetación y estilos aplicados de forma manual, sin frameworks.
